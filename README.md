# nawh.ai Premium Starter Template | قالب نواه المميز للمطورين

A premium, production-ready React starter template with bilingual support (Arabic RTL / English LTR), dark mode, and modern UI components. Perfect for selling on GitHub, ThemeForest, or CodeCanyon.

قالب جاهز للإنتاج ومبني باستخدام مكتبة React مع دعم كامل وثنائي للغات (العربية باتجاه RTL والإنجليزية باتجاه LTR)، الوضع الداكن، ومكونات واجهة مستخدم حديثة. مثالي للبيع على منصات GitHub أو ThemeForest أو CodeCanyon.

## Features | المميزات

### Core Features | المميزات الأساسية
- **Bilingual Support** - Full Arabic (RTL) and English (LTR) support with automatic layout mirroring
  - **دعم ثنائي اللغة** - دعم كامل للغتين العربية (من اليمين لليسار) والإنجليزية (من اليسار لليمين) مع قلب الاتجاهات تلقائياً.
- **Dark/Light Mode** - Smooth theme transitions with persistent user preferences
  - **الوضع الداكن والفاتح** - تنقل سلس بين السمات (Themes) مع حفظ تفضيلات المستخدم تلقائياً.
- **Mobile-First Design** - Fully responsive with Tailwind CSS
  - **تصميم متوافق مع الهواتف** - واجهات مرنة تماماً ومتجاوبة مع مختلف الشاشات باستخدام Tailwind CSS.
- **Premium UI** - Beautiful gradients, animations, and micro-interactions
  - **واجهة مستخدم احترافية** - تدرجات ألوان ساحرة، وتأثيرات حركية دقيقة وجذابة.
- **Clean Architecture** - Well-organized folder structure with reusable components
  - **بنية برمجية نظيفة** - هيكلة مجلدات منظمة بعناية مع مكونات (Components) قابلة لإعادة الاستخدام.

### Pages Included | الصفحات المضمنة
1. **Splash Screen** - Animated brand logo with fade transitions
   - **شاشة البدء (Splash)** - شعار متحرك للهوية مع تأثيرات تلاشي واختفاء سلسة.
2. **Onboarding** - 3-step introduction with swipe-like navigation
   - **التهيئة والتعريف (Onboarding)** - مقدمة تعريفيّة من 3 خطوات مع تنقل شبيه بالتمرير على الهواتف.
3. **Authentication** - Modern login/signup with social login mockups
   - **التسجيل والمصادقة** - صفحات تسجيل دخول وإنشاء حساب حديثة مع نماذج جاهزة للتسجيل الاجتماعي.
4. **Dashboard** - Stats, charts, and time-based greetings
   - **لوحة التحكم (Dashboard)** - إحصائيات، رسوم بيانية، وترحيب ذكي يتغير بحسب الوقت الموقّت.
5. **AI Playground** - Interactive chat interface for AI features
   - **ساحة تجربة الذكاء الاصطناعي** - واجهة محادثة تفاعلية مخصصة ومجهزة لربط ميزات الـ AI.
6. **Settings** - Language, theme, and account management
   - **الإعدادات** - التحكم باللغة، السمة، وإدارة الحساب الشخصي.

### Tech Stack | التقنيات المستخدمة
- **React 18** - Latest React with hooks
  - **React 18** - أحدث إصدارات ريأكت مع الاعتماد الكامل على الـ Hooks.
- **Vite** - Lightning-fast build tool
  - **Vite** - أداة البناء فائقة السرعة للمشاريع الحديثة.
- **Tailwind CSS** - Utility-first CSS framework
  - **Tailwind CSS** - إطار عمل التصميم السريع والأكثر كفاءة.
- **React Router 6** - Client-side routing
  - **React Router 6** - لإدارة وتوجيه مسارات الصفحات الداخلية للمستخدم.
- **Capacitor** - Native mobile deployment (iOS/Android)
  - **Capacitor** - المحرك المسؤول عن تصدير وإنتاج التطبيق ليعمل كـ تطبيق هاتف أصيل (Android / iOS).
- **Lucide React** - Beautiful open-source icons
  - **Lucide React** - مكتبة الأيقونات المفتوحة والمصممة بجمالية ممتازة.
